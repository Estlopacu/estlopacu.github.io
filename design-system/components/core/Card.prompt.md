Elevated content surface with blue-tinted elevation.

```jsx
<Card interactive>
  <h3>Contratista CR</h3>
  <p>Marketplace for the Costa Rican construction industry.</p>
</Card>
<Card variant="terminal">$ cat about.md</Card>
```

Variants: `default` · `sunken` · `terminal` (dark). Add `interactive` for hover-lift clickable cards.
