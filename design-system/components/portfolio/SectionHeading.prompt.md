Section header used across the portfolio — a `//` monospace eyebrow over a display title.

```jsx
<SectionHeading eyebrow="selected work" title="Things I've built" subtitle="A few projects I'm proud of." />
<SectionHeading eyebrow="experience" title="Where I've worked" align="center" />
```

The `//` prefix is added automatically. Use `align="center"` for hero/section intros.
