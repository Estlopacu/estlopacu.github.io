Circular social icon link with the heritage "swing" hover. Uses Lucide icons.

```jsx
<SocialLink icon="github" label="GitHub" href="https://github.com/Estlopacu" />
<SocialLink icon="linkedin" label="LinkedIn" href="https://www.linkedin.com/in/estlopacu/" />
<SocialLink icon="mail" label="Email" ghost href="mailto:estlopacu@gmail.com" />
```

Requires Lucide on the page: `<script src="https://unpkg.com/lucide@latest"></script>`. Use `ghost` on dark surfaces.
